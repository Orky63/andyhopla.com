Commercial website

NextFoundry — AWS-hosted commercial website

Status: Live

NextFoundry is a live website created as both a commercial proposition and a practical AWS/cloud project. It is hosted in AWS using S3, CloudFront, Route 53 and ACM, with a Lambda function supporting website contact-form functionality.

Purpose & practical focus

Taking a website from development through infrastructure, deployment and ongoing operation. Infrastructure has been developed using Infrastructure as Code and deployment automation, including Terraform and GitHub Actions.
